# Security

Please **do not** open a public issue for a security problem — in the SDKs or in the txApi
service itself.

Write to **support@txapi.cloud** with a description, the affected SDK and version, and how to
reproduce it. We answer as soon as we can and will tell you when a fix is released. Please give
us a reasonable time to fix the problem before you publish details.

Supported versions: the latest release of each SDK.
